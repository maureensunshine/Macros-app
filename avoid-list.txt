#
#  HOW THIS FILE WORKS
#  - Lines starting with # are notes. The app ignores them.
#  - Each rule is one line:   Name: other name, other name, ...
#  - Plurals are automatic. "onion" also catches "onions".
#  - Capitals and dashes don't matter. "Corn-Starch" = "corn starch".
#  - Put ! in front of a phrase to EXCLUDE it from that rule.
#      Example: "!peanut butter" stops the Dairy rule from
#      freaking out over peanut butter.
#  - Start a line with ? to make it a MAYBE rule. Maybes show up
#    as "check with the company" instead of a hard NO.
#
# ============================================================
